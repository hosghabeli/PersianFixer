## 📖 معرفی | Introduction

**PersianFixer** یک راه‌حل جامع، سبک و بدون نیاز به دسترسی ادمین برای حل مشکلات نمایش، چیدمان و تایپ زبان فارسی در محیط‌های هوش مصنوعی و کدنویسی است. این ابزار در دو قالب مجزا اما کاملاً یکپارچه عرضه می‌شود:

1. **نرم‌افزار دسکتاپ ویندوز (Windows Desktop Application):** پچ خودکار نرم‌افزارهای دسکتاپ شامل Google Antigravity، Visual Studio Code (سایدبارها و افزونه‌های Gemini, Copilot, Continue, Cline)، Claude Desktop، OpenCode و ChatGPT Windows.
2. **اکستنشن مرورگر (Microsoft Edge & Google Chrome Extension):** راست‌چین‌سازی هوشمند (RTL) و رندر فونت وزیرمتن در مرورگرهای اج و کروم برای وب‌سایت‌های ChatGPT, Claude, Gemini, DeepSeek, Perplexity، **سایدبار داخلی Copilot در مایکروسافت اج** و تمامی صفحات وب.

## ✨ قابلیت‌های کلیدی | Features

- 🔤 **نصب خودکار فونت وزیرمتن گوگل (Vazirmatn Variable)**:
  - نصب خودکار تمام وزن‌های ۱۰۰ تا ۹۰۰ در سیستم بدون نیاز به مجوز Run as Administrator با اطلاع‌رسانی زنده سیستمی (`WM_FONTCHANGE`).
- 📐 **تشخیص خودکار و هوشمند جهت متن (Smart RTL)**:
  - راست‌چین شدن هوشمند پیام‌ها، گفتگوها و دیالوگ‌های فارسی در دسکتاپ و وب.
- 📝 **پشتیبانی کامل از بلاک‌های مارک‌داون و متنی (RTL Markdown Blocks)**:
  - بلاک‌های متنی/مارک‌داون (`language-markdown`, `language-text`) به صورت خودکار راست‌چین شده و شکست خطوط و علائم نگارشی (`###`, `**`, پرانتزها و شماره‌ها) با قلم وزیرمتن اصلاح می‌شوند.
- 💻 **جداسازی و حفظ کدهای برنامه‌نویسی (LTR Isolation)**:
  - بلاک‌های کد برنامه‌نویسی (مانند Python, JS, C++, Go, Bash, SQL)، مسیرهای فایل و دستورات ترمینال کاملاً استاندارد و چپ‌چین باقی می‌مانند.
- 📊 **پشتیبانی کامل از جداول مارک‌داون (RTL Markdown Tables)**:
  - راست‌چین کردن خودکار ترتیب ستون‌ها و رندر روان متون داخل جدول با قلم وزیرمتن.
- ⚡ **پچ هوشمند ۱-کلیک (Master 1-Click Patch)**:
  - تنها با فشردن یک دکمه، تمام برنامه‌های نصب‌شده روی سیستم شما شناسایی و هم‌زمان پچ می‌شوند.
- 🟢 **نشانگر وضعیت جامع (Master Status Indicator)**:
  - نمایش زنده وضعیت اتصال، پچ بودن و آماده‌به‌کار بودن سیستم با یک نگاه.
- 📌 **اجرا در پس‌زمینه و System Tray**:
  - حضور سبک در کنار ساعت ویندوز با مصرف حداقل حافظه رم (کمتر از ۱۵ مگابایت).

## 📥 دانلود و راهنمای نصب سریع | Quick Start Guide

### روش ۱: نرم‌افزار دسکتاپ ویندوز (برای ابزارهای دسکتاپ)
به بخش [Releases](https://github.com/hosghabeli/PersianFixer/releases) مراجعه کرده و آخرین نسخه را دریافت کنید:
1. فایل نصاب `PersianFixer-v3.12.0-Setup.exe` را اجرا و نصب کنید (یا نسخه پرتابل `PersianFixer-v3.12.0-windows.zip` را استخراج کنید).
2. برنامه را باز کرده و روی دکمه بزرگ **«فعال‌سازی هوشمند تمام ابزارها»** کلیک کنید.
3. نرم‌افزارهای خود (VS Code, Antigravity, Claude و...) را اجرا کرده و از زبان فارسی روان لذت ببرید!

---

### روش ۲: نصب در مرورگر Microsoft Edge (مایکروسافت اج)
اکستنشن PersianFixer به طور ۱۰۰٪ از مرورگر مایکروسافت اج و **سایدبار کوپایلوت اج** پشتیبانی می‌کند:
1. فایل `PersianFixer-Chrome-Extension-v1.0.2.zip` را از بخش [Releases](https://github.com/hosghabeli/PersianFixer/releases) دریافت و استخراج کنید (یا از پوشه `extension` داخل مخزن استفاده کنید).
2. مرورگر **Microsoft Edge** را باز کرده و به آدرس زیر بروید:
   ```text
   edge://extensions
   ```
3. از منوی سمت چپ (پایین صفحه)، کلید **Developer mode (حالت برنامه‌نویس)** را روشن کنید.
4. در بالای صفحه روی دکمه **Load unpacked (بارگیری باز نشده)** کلیک کنید.
5. پوشه `extension` را انتخاب کنید.
6. کار تمام است! اکنون هم تب‌های وب (ChatGPT, Claude, Gemini و...) و هم **سایدبار Copilot اج** به زبان فارسی راست‌چین و با فونت وزیرمتن نمایش داده می‌شوند.

---

### روش ۳: نصب در مرورگر Google Chrome (گوگل کروم)
1. فایل `PersianFixer-Chrome-Extension-v1.0.2.zip` را استخراج کنید (یا از پوشه `extension` استفاده کنید).
2. در مرورگر کروم به آدرس زیر بروید:
   ```text
   chrome://extensions
   ```
3. گزینه **Developer mode** را از گوشه بالا فعال کنید.
4. روی **Load unpacked** کلیک کرده و پوشه `extension` را انتخاب کنید.

> **💡 نکته به‌روزرسانی:** برای دریافت آخرین تغییرات پس از دانلود نسخه جدید، فقط کافی است در صفحه افزونه‌های مرورگر (`edge://extensions` یا `chrome://extensions`) دکمه **بازخوانی (🔄 Refresh)** را روی کارت افزونه PersianFixer بزنید.

---

### روش ۴: اجرا از سورس کد دسکتاپ (مخصوص توسعه‌دهندگان)
پیش‌نیازها: پایتون ۳.۱۰+ و نود جی‌اس ۱۸+
```powershell
# ۱. کلون کردن مخزن
git clone https://github.com/hosghabeli/PersianFixer.git
cd PersianFixer

# ۲. نصب نیازمندی‌ها
pip install -r requirements.txt

# ۳. اجرای برنامه
python gui.py
```

## 📋 تاریخچه نسخه‌ها | Changelog

### Version 3.12.0 (جدید - New)
- 📝 **پشتیبانی کامل از بلاک‌های متنی و مارک‌داون (Markdown & Prose Code Blocks)**:
  - تشخیص هوشمند بلاک‌های متنی/مارک‌داون (`language-markdown`, `language-text` یا بلاک‌های کد متنی) حاوی متن فارسی و راست‌چین‌سازی کامل آنها (`dir="rtl"`).
  - اعمال قلم چشم‌نواز وزیرمتن و تصحیح چرخش و شکست خطوط فارسی و علامت‌های نگارشی (`###`, `**`, پرانتزها و شماره‌ها).

  - تفکیک قطعی از کدهای برنامه‌نویسی واقعی (Python, JS, C++, Go, Bash) که بدون تغییر کاملاً چپ‌چین و استاندارد باقی می‌مانند.

  - اضافه شدن دامنه‌های `edgeservices.bing.com` و `bing.com/chat` جهت اصلاح هوشمند زبان فارسی در سایدبار داخلی مایکروسافت اج.
  - افزودن راهنمای کامل نصب در مایکروسافت اج در مستندات و ریپازیتوری.
